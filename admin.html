Use the SVG Horizon Question Template. Details above are filled automatically from its Paper_Info sheet (you can change them).

3 · Seal & save

Locks the question paper and solutions with two secret keys, and saves the answer key privately in Supabase. Students cannot see anything yet.

4 · Publish to SVG Horizon

Puts the two sealed files on the website, checks they are reachable, then shows the exam in the student calendar.

No GitHub token in Settings, so upload the two files by hand:
  1. Download both files below.
  2. On GitHub, open your SVG Horizon repository → Add file → Upload files.
  3. Drag both files in, and in the file-name box type the folder path shown (e.g. ). Commit.
  4. Wait 1–2 minutes, then click Check & publish.

⚙️ School list (one-time setup, update any time)

In your Google Sheet: File → Download → Microsoft Excel (.xlsx), then choose that file here. It reads the Master tab columns Block · UDISE_Code · School Name · Management · Management Type · Category · Category Type. Existing schools are updated; new ones are added; nothing is deleted.

GitHub publishing (optional, recommended)

With a GitHub token, "Publish" uploads the sealed files for you. The token is stored only in this browser. Create one at GitHub → Settings → Developer settings → Fine-grained tokens, with access to only the SVG Horizon repository and permission Contents: Read and write.

Monthly clean-up

Keeps Supabase inside the free 500 MB. First download each exam's results (Results tab → Download CSV), then delete old attempts here. Exams, answer keys and students are kept.
